# Metro Dash

Corra por três faixas, desvie de trens e obstáculos, colete moedas e cumpra missões para desbloquear visuais. O jogo inclui um tutorial na primeira corrida e salva o progresso no navegador.

[Jogar Metro Dash na Kabem Jogos](https://jogos.kabemmanager.online/jogos/metro-dash/)

| Ação | Teclado | Tela de toque |
| --- | --- | --- |
| Mudar de faixa | ← e → ou A e D | Deslize para os lados |
| Pular | ↑, W ou Espaço | Deslize para cima |
| Deslizar | ↓ ou S | Deslize para baixo |
| Pausar ou continuar | Esc ou P | Botão de pausa |

Para testar localmente, abra `index.html` no navegador. A vitrine usa uma cópia desse mesmo HTML.
